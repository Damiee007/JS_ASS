Understanding var, let and const

In JavaScript, we use var, let, and const to store values. They look similar but work differently.

Feature var let const
Meaning The old way to make variables. The modern way to make changeable variables. Used for values that never change.
Scope Works everywhere inside a function. Works only inside the block where it’s created. Works only inside the block where it’s created.
Can you re-declare it? Yes, you can use the same name again. No, not in the same block. No, not in the same block.
Can you change its value? Yes, anytime. Yes, you can update it later. No, the value stays fixed.
Before it’s created Exists but shows “undefined”. Gives an error if used before creation. Gives an error if used before creation.
Best time to use Old code only (rare today). When the value can change. When the value should stay the same.
Example var name = "Damiee"; let age = 18; const country = "Nigeria";

NB: use let for most cases, and const when you don’t want the value to change.
